## Исправления при подготовке

- Read-only inspection использует `rescue=nologreplay`: live btrfs v7.1
  не принял отдельную опцию `nologreplay`. Это произошло до изменения диска.
- Точный размер диска 60 GiB и число vCPU 6 отличаются от первоначальных примерных
  64 GiB/4 vCPU. Сценарий и документация используют фактические значения.
- Настройка UEFI выполняется через libvirt; GRUB устанавливается с `--no-nvram`
  и fallback EFI-файлом, поскольку ISO исходно загружен через BIOS.
- Генератор lock учитывает epoch как в версиях pacman, так и в именах архивов:
  например, скачанный архив GRUB содержит `2:`. Первый запуск генератора отказался
  принимать такой файл; после исправления зафиксированы все 210 пакетов.
- `grubenv` сохраняет `next_entry=` с пустым значением после потребления;
  проверка должна требовать пустого значения, а не отсутствия переменной.
- Проверка fstab из chroot дала предупреждение о конфигурации live systemd;
  после реальной загрузки `findmnt --verify` завершился без ошибок и предупреждений.
- Предзагрузочная проверка файлов пакетов заметила UID/GID `/etc/resolv.conf`,
  скопированного live-средой. После запуска NetworkManager файл root:root 0644;
  повторная проверка пакета filesystem: 0 altered files. Изменённые backup-конфиги ожидаемы.

## Артефакты

- `domain-before.xml`: исходная persistent-конфигурация.
- `domain-uefi.xml`: подготовленная конфигурация.
- `domain-after.xml`: фактически принятая libvirt конфигурация.
- `firmware.sha256`: контрольные суммы OVMF code и шаблона NVRAM.
- `install.log`: полный вывод сценария без секретных значений.
- `installer-executed.sh`: точная версия сценария, реально выполненного при стирании
  и установке. Актуальная версия в `scripts/` дополнительно сохраняет source и lock
  непосредственно во время будущей установки; в этом запуске они добавлены после загрузки.
- `source.sha256`: контрольные суммы актуальных сценариев и параметров.
- `evidence/`: фактические конфигурации и сведения о сборке.
- `verify.log`: результаты после cold start.
- `user-access.log`: вход codex, sudo, DNS и доступ к архиву.
- `one-shot-before.log`, `one-shot-after.log`: Boot ID и состояние GRUB до/после перезапуска.
- `../../../manifests/bootstrap/lock.json`: нормализованный пакетный lock.
